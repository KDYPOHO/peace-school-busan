# 유관기관 협력 (대외협력팀)

- 담당: 대외협력팀 (`cooperation-team`)
- 목적: 현장교육 방문지·대학·지자체 협력 사항 정리
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 방문지별 운영 시간·휴관일·단체 예약·해설 신청 필요 여부('확인 필요' 표시)
2. 협력 대학·기관의 제공 사항과 요청 사항 구분
3. 협력 확정 전 홍보물에 기관명 기재 금지

## 산출물
- 협력 현황표
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 미확정 기관 공개 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 대외협력팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
