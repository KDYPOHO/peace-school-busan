# 6단계 제작 절차 (지침 고정 → 결재)

인자: 만들 산출물과 요구사항. 예) `/dept-produce 심화과정 모집 공고문`

## 1단계. 지침 고정
- `CLAUDE.md`를 읽고 이번 산출물에 적용되는 조항(명칭·로고·문체·중립·비용·개인정보)을 5줄 이내로 뽑아 이후 모든 부서 요청에 붙인다.

## 2단계. 자료 모으기 (사실 확인)
- 일정·정원·장소: `www/js/config.js`
- 과정·예산: 운영계획(안) (`/mnt/project-files/plan/` 또는 사용자가 준 파일, .docx는 `python3 scripts/dept_check.py --dump <파일>`)
- 확인되지 않은 정보는 "(안)", "확인 필요"로 표시할 목록을 만든다.

## 3단계. 구성안 먼저
- 담당 부서(아래 표)에 **본문 전에 구성안**(제목 후보 3개, 목차·카드 순서, 필수 정보 위치)만 요청한다.

| 산출물 | 담당(작성) 부서 |
|---|---|
| 모집 공고·포스터·안내문 | marketing-team |
| 카드뉴스·SNS·청년아카이브 기록 | social-team |
| 공문·운영 일정표 | operations-team |
| 예산표 | operations-team 작성 (finance-team는 검수 전용으로 결재 때 검산) |
| 누리집·앱 화면 | dev-team (화면 표현은 design-team) |

## 4단계. 초안
- 구성안 기준으로 담당 부서가 초안을 쓴다. 원고는 `docs/drafts/<YYYY-MM-DD>-<이름>.md`에 저장한다.

## 5단계. 다듬기
- 표기 기준(날짜·금액·명칭 첫 표기), 과장 표현 제거, 확인 필요 표시, 사진·로고 자리 `[로고: 공식 시그니처]`, `[사진1: 출처 필요]` 표시.

## 6단계. 결재
- `/dept-review <초안 경로>`를 실행해 결재 경로대로 검수한다.
- 상 등급 지적이 있으면 담당 부서가 고치고 해당 부서·법무·감사팀만 재검수한다.
- 최종본과 결재 보고서 경로를 사용자에게 알린다. 외부 게시·발송은 사용자가 직접 한다.
