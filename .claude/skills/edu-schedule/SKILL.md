# 추진 일정 관리 (교육운영팀)

- 담당: 교육운영팀 (`education-team`)
- 목적: 준비부터 결과 보고까지 역산 일정과 요일 검증
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 섭외(2개월 전) → 공고(6주 전) → 선발(4주 전) → 안내(1주 전) 간격 확인
2. 모든 날짜의 요일 검증(dept_check.py 요일 오류 0건)
3. 공휴일·시험 기간·폭염 시기 겹침 표시, 일정 변경 시 config.js 반영 요청

## 산출물
- 추진 일정표(단계·기한·담당·상태)
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 날짜·요일 오류 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 교육운영팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
