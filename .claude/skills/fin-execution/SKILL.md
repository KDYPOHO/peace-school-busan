# 집행 계획 (재무·회계팀)

- 담당: 재무·회계팀 (`finance-team`)
- 목적: 월별 집행 계획과 예비비 운용 기준 검토
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 월별 집행 계획 합 = 총액
2. 계약금·잔금 시점과 교육 일정 일치
3. 예비비 사용 조건(무료 한도 초과, 대관 미확보 등) 명시

## 산출물
- 집행 계획 검토표
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 합계 불일치 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 재무·회계팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
