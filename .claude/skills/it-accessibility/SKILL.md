# 화면·접근성 점검 (정보화팀)

- 담당: 정보화팀 (`it-team`)
- 목적: 앱·누리집 화면 구성과 웹 접근성 점검
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 대비 4.5:1 이상, 본문 16px 이상, 터치 영역 44px 이상, alt·lang·초점 표시
2. 360·768·1024·1440px에서 잘림·가로 스크롤 확인(Playwright 화면 캡처)
3. prefers-reduced-motion 존중, 로고는 움직이지 않음

## 산출물
- 접근성 점검표와 화면 캡처
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 대비 미달·alt 누락 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 정보화팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
