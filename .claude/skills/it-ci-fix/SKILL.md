# 자동 점검 오류 수정 (정보화팀)

- 담당: 정보화팀 (`it-team`)
- 목적: GitHub Actions 실패 원인을 찾아 수정
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 실패 작업 로그에서 첫 오류 메시지와 원인 파일 확인
2. 이 변경 때문인지, 기존 기준 브랜치에서도 실패하는지 구분
3. 시험을 끄거나 건너뛰는 방식의 해결 금지, 재실행은 1회까지

## 산출물
- 원인과 조치 기록
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 자동 점검 통과
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 정보화팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
