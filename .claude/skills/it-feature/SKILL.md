# 기능 개발 (정보화팀)

- 담당: 정보화팀 (`it-team`)
- 목적: 앱·누리집 기능을 설계·구현하고 시험
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 요구사항 → 화면 흐름 → 데이터 구조 → 보안 규칙 순서로 설계 메모 작성
2. 일정·정원은 www/js/config.js에서만 정의
3. 구현 후 npm test 통과와 360·1024px 화면 확인

## 산출물
- 변경 코드와 시험 결과
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 시험 실패 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 정보화팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
