# 시험판 배포 (정보화팀)

- 담당: 정보화팀 (`it-team`)
- 목적: 웹·안드로이드 APK·iOS TestFlight 시험판 배포 점검
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 배포 전 plan-regression(공개 전 재점검) 통과 확인
2. APP.version 갱신, 변경 내용 기록, 웹 자산 검증(scripts/verify_web_assets.py)
3. main 병합·스토어 제출은 총괄 결재 후 진행

## 산출물
- 배포 점검표
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 미조치 상 등급 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 정보화팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
