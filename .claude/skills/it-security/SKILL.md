# 보안 규칙 점검 (정보화팀)

- 담당: 정보화팀 (`it-team`)
- 목적: Firestore 보안 규칙과 비밀값 관리 점검
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 참가자는 본인 문서만, staff 문서 보유자만 관리 기능
2. 신규 컬렉션 규칙 누락(기본 거부) 여부, 비밀값(서비스 계정 키·비밀번호) 커밋 여부
3. 규칙 변경 시 npm run test:firebase 결과 첨부

## 산출물
- 보안 점검표
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 규칙 완화·비밀값 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 정보화팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
