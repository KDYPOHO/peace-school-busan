# 로고·명칭 사용 승인 확인 (법무·감사팀)

- 담당: 법무·감사팀 (`legal-team`)
- 목적: 기관 로고·명칭이 들어간 산출물의 사무처 승인 상태 확인
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 로고 원형 유지(홍보팀 pr-design 결과 확인)
2. 외부 공개 전 사무처 승인 여부 확인, '승인 대기'면 '공개 불가(내부 검토용)' 판정
3. 앱 스토어 출시물은 승인 문서 번호 또는 일자 기록

## 산출물
- 승인 현황표
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 승인 없는 외부 공개 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 법무·감사팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
