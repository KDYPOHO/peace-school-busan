# 사실관계 대조 (기획·품질팀)

- 담당: 기획·품질팀 (`quality-team`)
- 목적: 일정·정원·금액을 기준 자료와 한 줄씩 대조
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. 기준 자료: www/js/config.js(일정·정원), 운영계획(안), 사무처 공지
2. 계획안·누리집·앱·홍보물에 같은 사실이 같은 값으로 적혔는지 대조표 작성
3. 확인되지 않은 사실은 '(안)·추정·확인 필요' 표시 여부 확인

## 산출물
- 사실 대조표(항목·기준값·산출물값·일치 여부)
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 불일치 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 기획·품질팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
