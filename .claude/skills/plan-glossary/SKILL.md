# 공식 용어·표기 점검 (기획·품질팀)

- 담당: 기획·품질팀 (`quality-team`)
- 목적: 기관명·사업명·직함·날짜·금액 표기를 공식 기준에 맞춤
- 기준: 저장소 루트 `CLAUDE.md` 공통 규칙 10개

## 절차
1. docs/departments/glossary.md 표기 기준과 대조
2. 기관명 첫 표기 '민주평화통일자문회의', 이후 '민주평통'
3. 날짜 '2027. 4. 10.(토)', 금액 '1,234,000원', 직함은 실명 대신 직함
4. python3 scripts/dept_check.py 결과 중 공식 명칭·날짜 표기 항목 확인

## 산출물
- 표기 수정 목록(현재 → 수정)
- 보고는 개조식 공문서체로 작성하고, 모든 판단에 근거(파일:줄 또는 표 번호)를 붙임

## 합격선
- 표기 위반 0건
- 확인하지 못한 항목은 "미확인"과 필요한 자료를 적음

## 결재
- 기안: 기획·품질팀 → 협조: 관련 팀 → 최종 검수: 법무·감사팀 → 결재: 총괄(사용자)
- 병합·배포·외부 게시·공문 발송은 총괄 결재 후 사용자가 진행
