# 「한반도 평화학교」 앱 시연 대본(안)

- 용도: 2026. 12. 18.(금) 사무처장 간담회 앱 시연
- 시연 화면: 시연용 사본(병합·배포 후 `https://kdypoho.github.io/peace-school-busan/demo/`), 앱 버전 1.5.0
- 소요 시간: 약 7분(질의응답 제외)

## 1. 시연 원칙

○ 실제 참가자 자료는 화면에 띄우지 않음. 시연용 사본은 서버에 연결하지 않고, 이름·기록은 모두 "가상 참가자 nn" 형태의 가상 자료임
○ 시연 시각은 2027. 5. 15.(토) 14:20(기본과정 3강 진행 중)으로 고정되어, 출석·현황 화면이 실제 운영일처럼 보임
○ 기관 로고·명칭 사용과 외부 공개는 사무처 승인 전이므로, 시연은 "시험 운영 중인 시제품"으로 소개함

## 2. 사전 준비 (간담회 전날까지)

① 발표용 기기(노트북 또는 태블릿)에서 시연 주소를 한 번 열어 첫 화면이 뜨는지 확인
② 첫 화면의 "시연 자료 처음 상태로"를 눌러 가상 자료를 초기화
③ 통신 장애 대비: 시연 화면 캡처 6장(아래 순서)을 발표 자료에 예비로 넣어 둠
④ 휴대폰 실기기 시연이 필요하면 TestFlight·Play 내부 테스트 1.5.0 설치본을 준비(실제 서버 연결이므로 가상 계정만 사용)

## 3. 시연 순서

| 순서 | 화면 | 보여 줄 내용 | 설명 요지 | 시간 |
|---|---|---|---|---|
| ① | 첫 화면 → "참가자로 보기" | 오늘 강의 카드, 수료 요건(2/5강), 공지 | 전국 청년이 휴대폰 하나로 신청부터 수료까지 확인함 | 1분 |
| ② | 참가자 "출석" 탭 | QR 수강증, 온라인 출석 버튼 | 현장은 QR, 온라인은 정해진 시간에만 출석 인정 | 1분 |
| ③ | 참가자 "도우미" 탭 | "수료 조건이 뭐예요?" 질문 | 외부 AI를 쓰지 않는 공식 안내 기반 답변으로 AI 비용 0원 | 1분 |
| ④ | 로그아웃 → "관리자로 보기" → 현황 | 3강 출석 인원, 수료 위험 인원, 운영진 역할 | 운영 현황이 자동 집계되고, 권한을 관리자·운영진·심사위원으로 나눔 | 1분 30초 |
| ⑤ | 관리자 "참가자" 탭 | 가입 승인 대기 4명 일괄 승인, 반려 사유 선택, 현장 정원 표시 | 정원 100명이 차면 현장 신청자는 자동으로 대기자로 승인됨 | 1분 30초 |
| ⑥ | 로그아웃 → "심사위원으로 보기" | 심사 화면만 보임 | 외부 심사위원은 참가자 개인정보를 볼 수 없음 | 1분 |

## 4. 예상 질의응답

| 질문 | 답변 요지 |
|---|---|
| 운영 비용은 얼마인가? | 앱 서버(Firebase 무료 요금제)·배포(GitHub)는 무료 범위에서 운영함. 별도 비용은 앱스토어 개발자 등록비이며, 현재 총괄 개인 계정 사용 중임(기관 계정 이관은 결정 필요) |
| 개인정보는 안전한가? | 보안 규칙으로 본인 자료와 운영진 열람만 허용하고, 심사위원은 개인정보 열람 불가. 개인정보 보호책임자는 사무처 직원 지정 후 교체 예정임 |
| 휴대폰 알림은 되는가? | 강의 전날 저녁과 시작 1시간 전 기기 자체 알림을 1.5.0에 넣었음. 긴급 공지용 원격 푸시는 2027. 1.~3. 무료 방식으로 시험 예정(추정) |
| 온라인 출석은 어떻게 확인하나? | 현재는 강의 시간대에만 출석 버튼이 열림. 2027. 1.~3.에 강의 중 확인 코드 입력 방식 추가 예정 |
| 언제 정식 출시하나? | 사무처의 로고·명칭·수료증 명의 승인 후 스토어 정식 심사 신청 예정 |

## 5. 확인 필요 사항

○ 간담회장 인터넷 환경(시연 사본은 첫 접속 후 기기에 저장되지만, 첫 접속에는 인터넷 필요)
○ 화면 연결 방식(노트북 HDMI, 무선 미러링 등)
