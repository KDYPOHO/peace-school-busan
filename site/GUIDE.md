# 소개 누리집 제작 지침 (고정)

이 문서는 누리집을 고칠 때마다 먼저 확인하는 기준이다. 프로젝트 지침(공식 명칭·로고, 공문서체, 정치적 중립, 무료 운영)을 누리집 작업 단위로 옮긴 것이다.

## 1. 브랜드 (디자인 부서)
- 로고: 공식 파일만 사용. `img/signature-ko.jpg`(국문 시그니처 좌우조합), `img/emblem.jpg`(2색조합 엠블럼_b), `img/symbol.png`(2색조합 심벌_b 투명본). 비율·색상 변경, 그림자, 회전, 배지 장식 금지. 흰 바탕 위에만 시그니처를 놓는다.
- 색: 공식 심벌 남색 `#0F1D4A`, 금색 `#C5A366`. 보조색은 바다 `#2D5F93`, 안개 `#EEF2F6`. 강조색은 금색 하나만 쓴다.
- 글꼴: Pretendard 공식 부분 집합(KS X 1001, 무료, SIL OFL 1.1, `css/fonts/OFL.txt`). 원본 파일을 그대로 쓰고 변형하지 않는다. 제목 800, 본문 400, 행간 1.7.
- 반응형: 360px·768px·1280px 기준으로 확인. 가로 스크롤이 생기면 안 된다.
- 접근성: 본문 바로가기, 키보드 초점 표시, 대체 텍스트, 자동 재생 요소에는 정지 버튼, 동작 줄이기 설정 존중.

## 2. 화면 구성 (Stageshow 원칙 적용)
- 앱 화면은 실제 앱 캡처를 쓰고, 필요한 정보만 보이게 자른다(너무 빽빽함·너무 비어 있음 피하기).
- 휴대폰은 화면 가장자리에서 잘리게 배치한다(캡처를 카드에 붙인 느낌 금지).
- 모든 화면 요소가 같은 무게가 되지 않게, 한 구역에 강조는 하나만 둔다.
- 움직임에는 이유가 있어야 한다. 손가락 탭 → 화면 전환처럼 원인과 결과가 보이게 한다.
- 반복 모션은 끝 장면이 첫 장면과 같아 이음매가 보이지 않아야 한다. 가속·감속 곡선(ease-in-out)을 쓴다.
- 완성 후 녹화해 프레임을 펼쳐 보고, 튀는 움직임·잘린 글자를 고친다. 휴대폰 폭에서도 확인한다.

## 3. 문구 (마케팅 부서)
- 공문서 수준의 존댓말(누리집 안내문은 "~합니다"), 정치적 중립. 특정 정당·정책 평가 문구 금지.
- 확정되지 않은 일정·정원·지원 내용은 "(안)" 또는 "계획"으로 표시한다.
- 버튼 문구는 누르면 일어나는 일을 쓴다(예: "앱에서 신청하기").
- 첫 표기는 "민주평화통일자문회의", 이후 "민주평통". 직위는 직함으로 쓴다.

## 4. 검색 노출 (마케팅 부서)
- 페이지마다 고유한 제목·설명, Open Graph, 구조화 데이터(교육 과정·FAQ).
- 사무처 승인 전까지 `noindex`를 유지한다. 승인 후 해제.

## 5. 법무 점검 (법무 부서)
- 사진: 자유 이용 허락 사진만 쓰고 출처·라이선스를 바닥글 "사진 출처"에 적는다.
- 과장 표현 금지: "최고", "유일한 기회", 확정되지 않은 혜택 단정 금지. <!-- dept-check: ignore -->
- 개인정보: 앱 처리방침 링크를 바닥글에 굵게 표시. 누리집 자체는 개인정보를 수집하지 않는다(쿠키·분석 도구 없음).
- 기관 명칭·로고 사용은 사무처 승인 후 공개 배포한다.

## 6. 운영 (개발 부서)
- 정적 파일만 사용, GitHub Pages 무료 배포(`/home/` 경로). 빌드: `python3 site/build.py`.
- 공통 머리글·바닥글은 `build.py`에서 한 번만 고친다. 본문은 `pages/*.html`.
